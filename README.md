### 🌟 What is EduVerse?
EduVerse is a world-class, **glassmorphic** education platform that uses Machine Learning to predict student performance and provide actionable insights. Whether you are a student, teacher, or administrator, EduVerse gives you the tools to excel.

### 📖 Kaise Chalaye? (How to Run - Simple Hindi)
1. **Pehle code download karein:** Zip file download karein ya git use karein.
2. **Requirements install karein:** 
   ```bash
   pip install -r requirements.txt
   ```
3. **App start karein:**
   ```bash
   streamlit run app.py
   ```
4. **Bas ho gaya!** Ab browser mein `http://localhost:8501` kholein.
